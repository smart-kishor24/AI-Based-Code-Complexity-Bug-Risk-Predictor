# Trained Machine Learning Model Artifacts

This directory stores serialized models, scalers, feature column lists, and evaluation metrics generated by the training pipeline.

## Files
- `defect_predictor_rf.joblib`: Serialized `RandomForestClassifier` trained with balanced class weights and hyperparameter optimization.
- `feature_scaler.joblib`: `StandardScaler` fitted strictly on the training partition (preventing data leakage).
- `feature_columns.joblib`: Ordered list of input feature names required for aligned inference.
- `model_evaluation_metrics.json`: Empirical benchmark metrics (Accuracy, Precision, Recall, F1, ROC-AUC, Confusion Matrix, 5-Fold Stratified CV scores) for all evaluated models:
  1. Logistic Regression (Baseline)
  2. Decision Tree Classifier
  3. Random Forest Classifier (Primary Model)
  4. XGBoost Classifier

## Persistence Format
Models are serialized using `joblib` for compatibility across Python 3.11+ environments.
